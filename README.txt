FABIO KINGSTON LIMITED — starter website

WHAT THIS IS
- A responsive, single-page starter website for a company profile, product catalogue, WhatsApp enquiries, and wholesale/distributor leads.
- It does not process card payments yet. Orders are enquiries through WhatsApp.
- Product visuals and descriptions are illustrative placeholders.

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. The WhatsApp number has been set to 2347063457939. Confirm it is the correct business number before publishing.
3. Replace the illustrative product descriptions/visuals with your actual product photos and approved copy. The supplied wholesale pack prices have been added; confirm these are intended for public display.
4. Add your company email, address, business hours, product prices, and any required policies.
5. Check all company/product claims and regulatory wording before launch.

LOW-COST HOSTING
You can publish this static site for free using GitHub Pages. Create a GitHub account, create a public repository, upload index.html, then open Settings > Pages and choose the main branch as the publishing source. GitHub's interface can change, so follow its current Pages instructions if labels differ.
A custom domain (for example, fabiokingston.com) is optional and normally costs extra.

NOTE
This is a starter template, not a complete ecommerce checkout. For online payments, stock management, delivery fees, and customer accounts, add a supported ecommerce platform later.
